## 交互细节

- **拖放区**：M1 只接受 1 个文件；拖入多个时取第一个并提示"一次只能压一个"
- **文件对话框**：过滤 `mp4 / mov / m4v / avi`
- **目标体积**：数字输入框，右侧 20 / 50 / 100 三个快捷按钮
- **预计行**：选完文件就跑一次 `plan()`，实时显示将要用的档位和体积——家长不用等压完才知道
- **取消**：kill ffmpeg + 清理临时文件，回到"已选文件"状态
- **打开所在文件夹**：调系统文件管理器并选中输出文件（家长接着要去上传）

## egui 实现要点

1. **必须加载中文字体**，否则全是方框。用系统字体探测或直接打包一个开源中文字体
2. **压缩跑后台线程**：UI 线程只负责画；后台调 `compress()`，进度通过 `std::sync::mpsc` 传回来，UI 每帧 `try_recv` 更新进度
3. **core 的 `ProgressSink`** 在 GUI 侧实现成 channel sender，取消标志用 `Arc<AtomicBool>`（跟 CLI 的 `FlagSink` 同一套机制）
4. 输入框数值校验：上限必须 > 0，且不能小于音频本身需要的体积（否则直接提示）
